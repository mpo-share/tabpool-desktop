# Tabpool Desktop

Download Tabpool Desktop installers from [Releases](https://github.com/mpo-share/tabpool-desktop/releases/latest).

## Supported platforms

- Windows (x64): `.exe`
- macOS (Apple Silicon): `-mac-arm64.dmg`
- macOS (Intel): `-mac-x64.dmg`
- Linux (x64): `.AppImage`

This repository distributes desktop installers only.

Use `SHA256SUMS.txt` to verify downloaded files.
